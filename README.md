# tekomltd

The website of ТЕКОМ ООД (tekomltd.com) and its editor (control.tekomltd.com). One repo, two Next.js apps, each deployed as its own Netlify site, one Supabase project. Same shape as `blox-eng/vamyart`.

| Path | What |
|---|---|
| `DESIGN.md` | Design canon. Read before any visual decision. |
| `design/mockup/index.html` | The locked clickable mockup (open in a browser). `build.py` rebuilds it from `mockup.tpl.html`, `data/`, `covers/`, `logos/`. |
| `docs/superpowers/specs/2026-10-14-tekomltd-site-design.md` | The spec. |
| `docs/control-pane-mapping.md` | Every landing feature and the control-app screen that edits it. |
| `docs/superpowers/plans/2026-10-14-tekomltd-site.md` | The implementation plan (ASD-STE100). |

Project photos and texts in `design/mockup/` come from the current tekomltd.com and belong to ТЕКОМ ООД. Material brand logos belong to their owners and are used to name materials Tekom works with.
