# Security

Please do not report security vulnerabilities in public issues, pull requests or discussions.

Report them privately, by either:

- e-mail to **security@tekomltd.com**, or
- [GitHub private vulnerability reporting](https://github.com/blox-eng/tekomltd/security/advisories/new).

Include what you found, where (URL or file), how to reproduce it and the impact you expect. We confirm receipt within 3 working days and keep you posted until it is fixed.

Only the live site (tekomltd.com) and the `main` branch of this repository are in scope.
